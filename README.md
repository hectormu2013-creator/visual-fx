# 🏇 Visual-FX | Agencias Fenix 2026

![Visual-FX Live Streaming](https://img.shields.io/badge/Status-Active-brightgreen) ![NodeJS](https://img.shields.io/badge/Node.js-v18+-green) ![License](https://img.shields.io/badge/Platform-Fenix%202026-blue)

**Visual-FX** es el sistema profesional de transmisión hípica en vivo y multicanal desarrollado para las pantallas y televisores de las **Agencias Fenix**.

---

## 🌟 Características Principales

- 🏇 **30 Hipódromos Oficiales A-Z**: Cobertura en vivo de Gulfstream Park, Saratoga, Aqueduct, Belmont, Churchill Downs, Parx Racing, La Rinconada, Hipódromo de Palermo y muchos más.
- 🎛️ **Matriz Multicanal Flex (1 a 4 Pantallas)**: Permite proyectar simultáneamente 1, 2, 3 o 4 carreras en directo en una sola TV o monitor con control de audio independiente.
- 📡 **Bridge Automático RTN.tv**: Motor inteligente que sincroniza y renueva los feeds en vivo oficiales desde Racetrack Television Network (RTN).
- 🛡️ **Proxy HLS Anti-CORS**: Proxy interno express para reescritura de listas de reproducción `.m3u8` y transporte de segmentos `.ts` sin problemas de políticas de navegador.
- 🔑 **Autorización de Smart TVs por PIN**: Código de vinculación seguro (`FX-XXXX`) para activar pantallas en las distintas sedes de Agencias Fenix.
- 👥 **Jerarquía de Usuarios y Roles**: Control de acceso para Super Administrador, Jefe de Soporte Técnico y Encargados de Agencia.
- 📺 **Control Remoto para TV**: Soporte de navegación por teclado y flechas direccionales para Smart TVs sin ratón o pantalla táctil.

## 📖 Guía Rápida de Instalación

Para ver el manual completo paso a paso, consulta la [**Guía de Instalación Completa**](./GUIA_DE_INSTALACION.md).

```bash
# 1. Entrar al directorio
cd VISUAL_FX_PARA_GITHUB

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor
npm start
```

Abrir en el navegador: `http://localhost:3500`
